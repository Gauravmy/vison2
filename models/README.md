# Model Weights

No model weights are included. Place product detection/classification weights at `models/product_detector.pt`. For automatic category recognition, include exact class names `marker`, `plastic_bottle`, and `phone_charger` (or equivalent exact supported labels), configure `PRODUCT_CATEGORY_CONFIDENCE`, and set `PRODUCT_MODEL_VALIDATED=true` only after held-out evaluation. Generic labels such as COCO `bottle` can only suggest a category and require manual confirmation. Place custom defect weights at `models/defect_detector.pt`, and configure `DEFECT_CLASS_NAMES` to exactly match every class in that model.

Every defect label must be product-scoped: `marker_`, `bottle_` or `plastic_bottle_`, or `charger_` or `phone_charger_`. Inference filters boxes to the selected/identified product; unscoped classes disable the defect model. Defect inference is disabled until `DEFECT_MODEL_VALIDATED=true` is explicitly set after a documented domain-specific evaluation. Do not enable that flag solely because training or the validation script completed. See `data/README.md` and `scripts/validate_model.py`. Generic COCO weights may localize ordinary objects but are not defect models.
